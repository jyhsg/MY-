2_消失点标定
  - 单张消失线原始图片/19/88.jpg
  - 单张消失线标定图.jpg
  - 消失点标定实验报告.tex
  - calibrate_vanishing_point.py
  - 消失点标定结果.json

两份报告相互独立。LaTeX 的目录和图、公式引用依赖 .toc/.aux 文件，不能只编译一轮；单次编译会出现目录空白和“??”引用。推荐在提交包根目录运行：

  powershell -NoProfile -ExecutionPolicy Bypass -File .\编译报告.ps1

该脚本会对两份报告分别连续运行 3 轮 XeLaTeX，生成目录并解析全部交叉引用，然后清理中间文件。也可以在各自目录中手动连续运行 2--3 次 XeLaTeX，或使用 latexmk -xelatex。

代码依赖见 requirements.txt。提交包已经包含复现实验所需的 38 幅张氏标定图像和 1 幅消失点原始图像，无需依赖外部数据。进入相应子目录后运行：

  python calibrate_zhang.py --data .\棋盘格标定图片 --output .
  python calibrate_vanishing_point.py --data .\单张消失线原始图片 --output .

======================================================================
学生与 AI 的分工说明
======================================================================

本作业采用“学生负责总体方向、核心方案和最终技术判断，AI 负责工程修改、结果核对与文档制作”的协作方式。以下按本次协作开始前已有材料、AI 后续实际产出及最终复核责任分别说明。

一、学生（贾宇航）提供及负责的部分

1. AI 介入前已有的学生材料
  - 提供课程作业要求、完整标定数据集和《相机标定方法与流程总结.md》参考资料。
  - 提供已能表达总体思路的初始工程，包括张氏标定程序、消失点标定程序、Markdown 报告初稿及已有实验结果。
  - 初始工程已采用“多图棋盘格张氏标定”和“单图正交消失点标定”两条实验路线，包含角点检测、标定调用、直线拟合、消失点计算和结果输出等主要算法框架。

2. 学生负责的总体方向与核心方案
  - 决定最终保留张氏标定和消失点标定两种方案，并按课程要求拆分为两个独立提交目录。
  - 负责张氏法中棋盘规格、单位方格坐标、数据筛选原则、内外参定义、畸变模型及误差评价指标等核心方案选择。
  - 负责消失点法中两组正交方向、主点位置、零 skew、fx=fy、焦距恢复、旋转恢复及不可观测量等核心假设与方案选择。
  - 决定最终采用哪些图像、参数、结果图和实验结论，并对不符合课程要求的内容作出取舍。

3. 学生承担的核心代码与技术说明责任
  - 学生提供的初始代码已经包含棋盘世界点构造、OpenCV 标定调用、重投影误差计算、两组直线拟合、正交消失点焦距计算和旋转构造等核心模块。
  - 学生负责掌握并说明张氏法的单应性与旋转正交约束、畸变模型、重投影误差和方格尺度含义。
  - 学生负责掌握并说明消失点正交约束、焦距公式、旋转矩阵构造，以及平移和绝对尺度不可由消失点单独恢复的原因。
  - 学生承担最终提交和答辩责任；AI 修改过的代码与文字须经学生复核后方可作为最终作业内容。

二、AI 实际完成或修改的部分

1. 工程实现与代码修改
  - 扫描并核对图像数量、分辨率、棋盘规格、已有输出和程序运行环境。
  - 修改依赖加载逻辑，修复本地 .deps 可能覆盖当前有效 Python 环境的问题。
  - 为两份程序增加 --data 和 --output 命令行参数，使提交包可以直接使用包内数据复现。
  - 检查并修改数据范围说明、文件路径、结果字段、候选图像评分说明和部分代码注释。
  - 重新运行两份程序，核对 JSON、CSV、图片和报告中的数值一致性。

2. 结果检查与提交材料制作
  - 整理并核对内参矩阵、畸变系数、重投影误差、消失点、消失线、焦距和旋转矩阵等结果。
  - 生成或整理棋盘角点拼图、去畸变对比图和单张消失线标注图。
  - 按作业要求复制实际使用的 38 幅棋盘格图像和 1 幅消失点原始图像，并建立两个独立目录。
  - 清理缓存和编译中间文件，验证目录内容、图片引用、脚本语法和压缩包条目，生成最终 ZIP 文件。

3. 文档编写与格式转换
  - 审查 Markdown 报告初稿中的理论表述、数据范围、数值和可观测性说明，并提出修正。
  - 对报告内容进行较大幅度的整理和润色，转换为 LaTeX，并拆分为独立的张氏标定报告和消失点标定报告。
  - 编写或修改文件清单、复现命令、目录说明及本分工说明。
  - 检查两份报告能否独立阅读，确认图片引用、公式、表格和各自结果文件相互对应。

三、责任边界说明

  - 总体方法、关键假设、参数选择、结果取舍和最终提交决定由学生负责。
  - AI 对代码、报告和提交材料进行了实质性修改与制作，上述 AI 产出不声明为学生独立完成。
  - 最终提交前，学生应逐项复核 AI 修改或生成的代码、公式、实验数值和文字内容；只有经学生理解和确认的内容才进入最终提交。
  - 学生应能够独立说明两种标定方法的原理、实现步骤、实验结果及局限，并对最终作业的正确性负责。
